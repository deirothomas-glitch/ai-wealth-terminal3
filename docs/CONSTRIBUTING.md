# Contributing to AI Wealth Terminal

Merci de contribuer au projet.

---

# Objectif

L'objectif est de maintenir un code propre, stable et facilement maintenable.

Toutes les contributions doivent respecter l'architecture du projet.

---

# Avant de commencer

Lire obligatoirement :

- PROJECT_VISION.md
- DEVELOPMENT_GUIDE.md
- ARCHITECTURE.md
- CODING_STANDARDS.md
- ROADMAP.md
- AI_PROMPTS.md

---

# Règles

Ne jamais casser une fonctionnalité existante.

Respecter la modularité.

Documenter toute évolution importante.

Écrire un code lisible.

Tester les modifications.

---

# Style

Le projet suit :

- PEP8

- Architecture modulaire

- Une responsabilité par fichier

- Documentation obligatoire pour les évolutions importantes

---

# Pull Requests

Une Pull Request doit :

- expliquer le problème résolu
- décrire la solution proposée
- indiquer les fichiers modifiés
- rester cohérente avec la vision du projet

---

# Philosophie

Chaque contribution doit améliorer :

la qualité

la stabilité

la lisibilité

la maintenabilité

du projet.

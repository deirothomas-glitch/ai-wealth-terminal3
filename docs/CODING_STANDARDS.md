# Coding Standards

## Principes

Le code doit être :

- simple
- lisible
- documenté
- modulaire
- facilement testable

---

## Python

Respecter PEP 8.

Utiliser des noms explicites.

Éviter les fonctions trop longues.

Éviter les variables globales.

---

## Streamlit

Une page = une responsabilité.

Limiter le code métier dans les pages.

Les calculs doivent être placés dans les modules métier.

---

## IA

Les appels à OpenAI doivent être isolés.

Les prompts doivent être documentés.

Les erreurs doivent être gérées proprement.

---

## Git

Chaque évolution importante doit être accompagnée d'un message de commit clair.
